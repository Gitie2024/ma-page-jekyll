# Jekyll : Le moteur derrière ce site

Après avoir exploré les différentes options pour créer un site, j'ai décidé d'utiliser **Jekyll**. Voici les trois raisons principales qui m'ont convaincu :

### 1. La simplicité du Markdown
Pas besoin d'interface complexe. J'écris mon contenu en Markdown, et Jekyll s'occupe de la mise en page. C'est propre, rapide et efficace.

### 2. Intégration native avec GitHub
Comme Jekyll est le moteur officiel de **GitHub Pages**, le déploiement est automatique. Dès que je fais un `git push`, mon site est mis à jour en quelques secondes.

### 3. Pas de base de données
Tout est statique. Cela signifie que le site est extrêmement sécurisé (difficile de pirater ce qui n'est que du texte !) et qu'il se charge à la vitesse de l'éclair.
